## Что входит в цену дешевого Windows VPS, а что нет

Лицензия Windows Server почти всегда уже заложена в месячную ставку. Так у MakeCloud, у RUVDS (официальный партнер Microsoft по программе SPLA) и у ОБИТ, которые прямо пишут, что покупать и продлевать лицензию отдельно не нужно. У AvaHost тарифы тоже включают Windows Server, управление идет через RDP и Server Manager, предустановленной панели нет.

Дальше начинается то, что в строке «лицензия включена» не видно.

**RDP-лицензии.** В состав Windows Server входят две лицензии для административного подключения по удаленному рабочему столу. Если по RDP должны одновременно работать несколько сотрудников, нужны пользовательские лицензии, и ОБИТ, например, согласует их количество отдельно. Для терминального сервера на пятерых это ощутимая сумма сверх аренды, и она не появляется в калькуляторе при заказе.

**Лицензии 1С.** Их в аренду не включают. ОБИТ говорит об этом прямо: в стоимость входит только Windows Server, платформу клиент покупает сам. У остальных провайдеров действует то же правило, даже если в описании тарифа стоит «для 1С».

**Панель управления.** У AvaHost Plesk — платная опция, бесплатные панели можно поставить самостоятельно или через поддержку. У RUVDS ISPmanager бесплатно до конца 2026 года на любом тарифе. Если панель нужна, разница в несколько сотен рублей в месяц.

## Хватит ли 1 ГБ RAM для Windows Server

Формально Windows Server 2022 ставится на 2 ГБ RAM и 32 ГБ диска. На 1 ГБ система либо не встанет в графическом режиме, либо будет постоянно уходить в своп, и RDP начнет подтормаживать уже при открытом браузере. Такие тарифы берут под Server Core, узкие задачи вроде Telegram-бота или под тестовый стенд, который включают на пару часов.

Для рабочего сервера ориентируйтесь на рекомендацию ОБИТ: под нагрузкой нужно от 2 vCPU и 4 ГБ RAM. Это же значение разумно считать нижней границей для 1С на 3–5 пользователей и для сайта на ASP.NET с базой. Терминальному серверу на 10 человек нужно больше, и конфигурацию можно нарастить позже без переустановки системы.

Отдельно про диск. 10–20 ГБ хватает только на саму систему. Windows Update, файл подкачки и логи съедят несколько гигабайт в первый месяц, а 1С и SQL Server легко добавят еще десятки. Если в тарифе 10 ГБ SSD, считайте это тестовой машиной, а не рабочим сервером.

## Три ошибки, которые стоят дороже самой аренды

**Выключенный сервер продолжает тарифицироваться.** RUVDS прямо пишет: оплата идет за весь период от создания сервера до удаления, потому что ресурсы зарезервированы под вас независимо от состояния машины. Если план — включать VPS на несколько часов в день, помесячная аренда невыгодна. Ищите почасовую тарификацию: у ОБИТ она есть, от 1,175 ₽/час на младшем тарифе.

**Многопользовательский RDP требует отдельных лицензий.** Две административные сессии входят в Windows Server, все что сверху — покупается. Провайдеры не всегда пишут это на странице тарифа, а при подключении третьего сотрудника сервер просто откажет в сессии.

**Локация решает, можно ли хранить персональные данные.** Российская площадка ОБИТ аттестована под 152-ФЗ, поэтому 1С или CRM с данными клиентов можно разместить там и пройти проверку. У RUVDS дата-центры в России, Казахстане, Швейцарии, Нидерландах и Великобритании, и выбор страны при заказе меняет не только цену, но и применимое законодательство. Для зарубежных проектов это плюс, для работы с персональными данными россиян — риск.

## Можно ли поставить на VPS Windows 10 или 11

Нет. Провайдеры сдают в аренду только серверные редакции: ОБИТ предлагает Windows Server 2019, 2022 и 2025 Standard, про Windows 10 и 11 отвечает отказом. Причина в лицензировании: клиентская ОС не предназначена для одновременной работы нескольких удаленных пользователей, а серверная — предназначена.

Если нужен именно «удаленный рабочий стол как на домашнем ПК», это решается терминальным сервером на Windows Server с RDS, а не клиентской версией. И помните про лицензии на пользователей.

## FAQ

**Входит ли лицензия Windows в стоимость?**
У MakeCloud, RUVDS, ОБИТ и AvaHost — да, лицензия Windows Server уже в цене, отдельно покупать и продлевать ее не нужно. Это не отменяет доплат за RDP-пользователей и 1С.

**Есть ли бесплатный тест?**
У RUVDS новый пользователь получает 3 дня теста на любой конфигурации дешевле 3 000 ₽, для регистрации нужны только телефон и почта. Это скорее исключение: у большинства провайдеров пробного периода нет, а почасовая тарификация выполняет ту же роль.

**Можно ли расширить конфигурацию без переустановки?**
У ОБИТ можно нарастить CPU, RAM и диск без остановки сервера и переустановки системы. У AvaHost конфигурации фиксированы по тарифам, переход на старший делается через панель.

**Сколько ждать после заказа?**
AvaHost выдает сервер с уже работающим RDP, настройка дисплей-сервера и VNC не требуется. RUVDS запускает VPS за секунды, ОБИТ — после пополнения баланса в панели, HOSTKEY обещает не больше 15 минут на создание Windows VPS.

**Подойдет ли дешевый VPS под игровой сервер?**
Для небольшого сервера на несколько человек — да, если хватает 2 vCPU и 4 ГБ RAM. Для публичного проекта с десятками игроков берите конфигурацию с запасом по CPU: игровой процесс чувствителен к steal time, а на дешевых тарифах соседи по хосту заметны.
